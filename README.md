# Address-book-device
This is the implementation of the address book device. It mimics a Linux-based command line database program. It will prompt users to input commands, and all the while stores data like usernames and passwords. A user with admin permissions can manage this information.

# 1. Install Python 3.10+ (comes with Ubuntu 22.04)
sudo apt install python3 python3-pip

# 2. Install dependencies
pip3 install -r requirements.txt --break-system-packages

# 3. Run
python3 aba.py
